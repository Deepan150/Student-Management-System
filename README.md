# Student Management System

A full-stack Student Management System built using HTML, CSS, JavaScript, jQuery, Python Flask, and SQLite.

This project allows users to manage student records through a simple and responsive web interface.

---

## 🚀 Features

- 🔐 Login system
- 📊 Dashboard
- 👨‍🎓 Student management
- ➕ Add student
- 👀 View student list
- ✏️ Edit student details
- 🗑️ Delete student records
- 🔍 Search students by name or course
- ✅ Form validation
- 📱 Responsive user interface
- 👁️ Password show/hide
- ✨ jQuery animations and interactions
- 💾 SQLite database integration
- 📈 Dynamic student count on dashboard
